# Student ID Card Generator

A simple and lightweight web-based Student ID Card Generator by **Royal Technologies**.

Create professional student ID cards directly in your browser using a clean, responsive interface. No backend or database is required for the basic generator.

## Live Demo

[Open Student ID Card Generator](https://royal-technologies.github.io/idcardcenerator/)

## About

**Student ID Card Generator** is a browser-based tool designed to make student identity card creation easier and faster.

It can be used by schools, colleges, universities, training institutes, coaching centers, organizations, and other educational institutions that need a simple way to generate student cards.

The project is built as a lightweight frontend application and can be hosted easily using GitHub Pages or any standard web server.

## Features

* Generate student ID cards from a web browser
* Simple and easy-to-use interface
* Student information entry

* Instant card preview

## Installation

Clone the repository:

```bash
git clone https://github.com/Royal-Technologies/idcardcenerator.git
```

Open the project folder:

```bash
cd idcardcenerator
```

Then open `index.html` in your browser.

You can also upload the project directly to a web server.
